概念详细解释

覆盖微观经济学核心考点 · 通俗易懂 · 考试向

📌 成本三兄弟：TFC / TVC / TC 核心

TFC (Total Fixed Cost) = 总固定成本。不随产量 Q 变化，即使 Q=0 也存在（如租金、设备折旧）。所以图形是 水平直线。

TVC (Total Variable Cost) = 总可变成本。随产量 Q 增加而增加（如原材料、工资）。图形从原点出发，向上倾斜，先以递减速率上升，后以递增速率上升（边际报酬递减）。

TC (Total Cost) = TFC + TVC。因为 TFC 是常数，所以 TC 与 TVC 平行，TC 始终比 TVC 高一个 TFC 的距离。

📐 关系：TC = TFC + TVC

  • Q=0 时，TC = TFC，TVC = 0
  • TFC 永远水平；TVC 从原点开始上升；TC 从 TFC 高度开始上升
  • TC 与 TVC 的垂直距离 = TFC（恒定）

📉 边际报酬递减规律 必考

边际产量 MP：每增加一单位可变投入所增加的产量。

规律：在固定投入不变时，连续增加可变投入，MP 最终会递减。

  • MP 上升 → 边际成本 MC 下降
  • MP 下降 → MC 上升
  • MP 最高点对应 MC 最低点

💡 记忆："先递增后递减，交点即最优"——MP 与 AP 相交于 AP 最高点。

⚖️ 供需关系与均衡 基础

需求定律：价格 P ↑ → 需求量 Qd ↓（其他条件不变）。需求曲线 向下倾斜。

供给定律：价格 P ↑ → 供给量 Qs ↑。供给曲线 向上倾斜。

均衡点：Qd = Qs 时的 P 和 Q。此时市场出清，无短缺无过剩。

  • 需求增加（曲线右移）→ 均衡 P↑, Q↑
  • 供给增加（曲线右移）→ 均衡 P↓, Q↑
  • 需求减少 → P↓, Q↓；供给减少 → P↑, Q↓

📏 弹性 (Elasticity) 高频

需求价格弹性 Ed：需求量对价格变化的敏感程度。

Ed = %ΔQd / %ΔP（绝对值通常取正）

  • Ed > 1：富有弹性（奢侈品）→ 降价增收
  • Ed < 1：缺乏弹性（必需品）→ 涨价增收
  • Ed = 1：单位弹性 → 收入不变

供给弹性 Es：供给量对价格变化的敏感程度，公式类似。

🏢 市场结构对比 重点

完全竞争：无数小厂商，同质产品，价格接受者，P = MR = AR，长期利润为零。

垄断：一家厂商，价格制定者，MR < P，存在进入壁垒，长期可获超额利润。

垄断竞争：许多厂商，差异化产品，短期像垄断，长期利润趋零。

寡头：少数几家，相互依存，博弈论。

📊 短期成本曲线关系 必考

MC / AVC / AC 关系：

  • MC 与 AVC 相交于 AVC 最低点
  • MC 与 AC 相交于 AC 最低点
  • MC < AC 时，AC 下降；MC > AC 时，AC 上升
  • AVC 先于 AC 到达最低点（因为 AC 包含 AFC，AFC 一直下降）

📐 AC = AVC + AFC，AFC = TFC / Q 一直下降。

全套公式专区

分类清晰 · 字母含义 · 使用场景 · 直接背诵

💰 成本公式

TC = TFC + TVC — 总成本 = 总固定 + 总可变

AC = TC / Q — 平均总成本

AVC = TVC / Q — 平均可变成本

AFC = TFC / Q — 平均固定成本

MC = ΔTC / ΔQ — 边际成本

字母含义：TC总成本，TFC总固定，TVC总可变，Q产量，AC平均总成本，AVC平均可变，AFC平均固定，MC边际成本。

📌 使用场景：计算短期成本、分析成本曲线关系。

📈 收益公式

TR = P × Q — 总收益

AR = TR / Q = P — 平均收益

MR = ΔTR / ΔQ — 边际收益

字母含义：TR总收益，P价格，Q销量，AR平均收益，MR边际收益。

📌 使用场景：完全竞争下 P = AR = MR；垄断下 MR < AR。

📐 弹性公式

Ed = %ΔQd / %ΔP — 需求价格弹性

Es = %ΔQs / %ΔP — 供给价格弹性

Ey = %ΔQd / %ΔY — 收入弹性

Exy = %ΔQx / %ΔPy — 交叉弹性

字母含义：Ed需求弹性，Es供给弹性，Ey收入弹性，Exy交叉弹性，Y收入。

📌 使用场景：判断商品性质（正常品/劣等品/替代/互补）。

⚖️ 均衡与利润公式

Qd = Qs — 市场均衡条件

Profit = TR - TC — 利润

π = (P - AC) × Q — 利润的另一种表达

MR = MC — 利润最大化条件

字母含义：Qd需求量，Qs供给量，π利润，MR边际收益，MC边际成本。

📌 使用场景：求均衡价格/产量、判断盈亏、定价决策。

📉 边际与平均关系

MP = ΔTP / ΔL — 边际产量

AP = TP / L — 平均产量

MP > AP 时，AP 上升；MP < AP 时，AP 下降；MP = AP 时，AP 最大。

📌 使用场景：分析生产函数、边际报酬递减。

🧮 其他常用公式

P = AR = MR（完全竞争）

Lerner Index = (P - MC) / P — 垄断势力度

Consumer Surplus = ½ × (Pmax - P) × Q

Producer Surplus = ½ × (P - Pmin) × Q

📌 使用场景：福利分析、市场效率。
